## 先看哪些

建议先看《我对博客的一些想法》《2019走了，2020来了》、7 篇料理记录和 ARTS 第 0–2 周。它们有真实经历、具体反馈，最能构成个人博客的内容。旧技术文章适合标注原年份留存；空白、欢迎页和默认示例无需为了数量而发布。

评分是主观的“个人博客保留价值”，综合个人经验/不可替代性、完成度、长期阅读价值。不是文笔评判，也不等于技术内容已按今天的环境验证。8–10 优先保留，6–7 保留或小修，3–5 留档/补写，0–2 测试或占位，通常不发布。**低分内容也已完整迁入草稿，没有替你删除。**
